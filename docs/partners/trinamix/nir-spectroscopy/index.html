trinamiX Mobile NIR Spectroscopy Solution – Kunststoffidentifikation jederzeit und überall

Erfahren Sie, wie die innovative Handheld-Lösung von trinamiX die Identifikation von Kunststoffen auf ein neues Level hebt. Mit einer leistungsstarken Kombination aus mobiler Hardware, Datenanalyse und Materialexpertise wird die Unterscheidung von Kunststoffen so einfach wie nie zuvor.

Mobile und Schnelle Kunststoffidentifikation

Dank des tragbaren Handheld-Geräts von trinamiX können Kunststoffe direkt vor Ort und innerhalb von Sekunden identifiziert werden – sogar ohne Internetverbindung. Diese benutzerfreundliche Lösung verbessert die Sicherheit und Transparenz Ihrer Materialströme erheblich.

Vorteile der trinamiX Lösung

  • Schnell und Zuverlässig:
    Identifikation von Kunststoffen in Sekundenschnelle.
  • Benutzerfreundlich:
    Einfaches Handling für jedermann.
  • Sicherheit:
    Verbessern Sie Ihre Wareneingangskontrolle durch zuverlässige Vor-Ort-Identifikation verschiedener Kunststoffe.
  • Transparenz:
    Das Kundenportal ermöglicht die Dokumentation, Visualisierung und Analyse eingehender und ausgehender Abfallströme.

Verbesserung der Entscheidungsfindung dank NIR-Spektroskopie

Die Lösung bestehend aus einem robusten, mobilen NIR (Nah-Infrarot)-Spektrometer macht das Unsichtbare sichtbar und vereinfacht die Überprüfung eingehender Materialien vor Ort.

So funktioniert das trinamiX Mobile NIR Spectroscopy-Gerät:

Breite Palette an identifizierbaren Kunststoffen

Die Lösung von trinamiX kann über 30 Kunststoffe zuverlässig identifizieren, darunter:

- Thermoplaste: PLA, PA, POM, PB, PBT, PPSU, PI, HDPE, LDPE, PP, PVC, PS, PEEK
- Blends und Spezialpolymere: ABS-PA, PC-ABS, SBS/SEBS, PC, SAN, PU, PET-A, ASA, ABS, PET-G, PAI, PPS, PMMA, PVDF, PEI, PESU, PSU, PE/PP Blends
- Folien: Mono-Material und Multi-Material Folien

(Kohlenstoffschwarze Kunststoffe können nicht erkannt werden.)

Technische Daten

Die trinamiX Mobile NIR Spectroscopy Lösung bietet eine kompakte und leistungsstarke Lösung zur Messung und Analyse, die sich nahtlos in digitale Umgebungen integriert.

  • Batteriekapazität für bis zu 6.000 Messungen
  • Kompakte Größe, etwas größer als ein Smartphone
  • Drahtlose Verbindung via Bluetooth® zu Smart-Geräten und Internetanbindung zum Kundenportal
  • Datenspeicherung in der MS Azure Cloud (bereitgestellt von BASF SE)
  • End-to-End-Verschlüsselung (SSL, AES 256)
  • Kompatibel mit Android, iOS und Windows
  • Kundenportal für erweiterte Analysen
  • Nutzung firmeneigener chemometrischer Modelle
